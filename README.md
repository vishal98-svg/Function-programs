# JavaScript For Loop and Functions

This project explains the basics of JavaScript `for` loops and functions with simple examples.

## What is a `for` Loop?

A `for` loop repeats a block of code while a condition is true.

### Syntax

for (initialization; condition; update) {
  // code to execute
}

# JavaScript Arrow Functions

This project explains JavaScript arrow functions with simple examples.

## What Is an Arrow Function?

An arrow function is a shorter way to write a function in JavaScript. It uses the `=>` symbol.

## Syntax

```js
const functionName = (parameters) => {
  // Code to run
};
